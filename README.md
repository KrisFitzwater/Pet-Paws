# Paw Pals

A pet care game for children aged 5 to 8. Choose a puppy, kitten, bunny, hamster or pony, then feed, groom, walk, play with and teach your pet. Earn stars and spend them in the sticker book.

Everything is in `index.html`, with no build step. Progress is saved in each device's browser.

Play it on a phone: open the GitHub Pages address, then use **Add to Home Screen**.
